# 栈闩工房

机关推箱子纯前端工房。不同种类的箱子触发对应踏板，踏板改变门与地板，记录步数并保存已完成关卡的最佳成绩。

## 穿孔搬运琴

首屏的「穿孔搬运琴」为多个起始货位共用同一只纸筒：

- 每排可打一个方向孔、一个借带孔，或一个按当前踏板明/暗选孔的岔孔。
- 主筒奏完自动回头；任意货位交齐立即停止。
- 最多两条孔带，支持 `主筒 → 甲带 → 乙带` 嵌套；静态借带图出现递归会判无效。
- 总排数包含主筒和所有非空孔带；运行时纸排读数包含每次借带展开后的排。超过当班 `24` 读判失败。
- 步数牌分开展示 **纸排已读/总排数**、**实际搬步**、**被挡指令**。
- 点「逐排下一读」或「自动奏筒」可看画布推箱并开启听音；点孔旁「验孔」可查看该孔在每种货位、每次借带调用中的结果和失败归因。
- 「手卷接管方向键」后，方向键/WASD 只做实际推动，不推进纸排；「交还原排位」会回到接管前的孔。
- 「查找最省纸方案并归档」会载入 `5` 排明暗对孔方案、在全部货位运行时复验，并写入 `localStorage` 的纸筒目录。随库求解器也可完整枚举 `5` 排以下的 2,507,664 个全语法候选；目录按总排数保存，不会被单次最快手动成绩替换。
- 可载入「错误合并案」和「借带失败案」查看只按方向字串合并、以及重复借带在特定调用次序中被挡的诊断轨迹。

## 本地运行

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run typecheck
npm run build
```

## Docker

```bash
docker compose up --build
```

浏览器打开 http://127.0.0.1:8030
